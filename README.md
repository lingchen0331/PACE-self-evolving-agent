## Installation and serve

1. Clone the repository:

2. Install vllm dependencies via `uv`:
   ```bash
      ./scripts/install_vllm.sh
   ```
   It sets up the environment and downloads the default local model set:
   `qwen3-local` (`Qwen/Qwen3-4B-Instruct-2507`) and `qwen3.5-local` (`Qwen/Qwen3.5-9B`).

4. Host the model checkpoint with vllm
   ```bash
      source .venv/bin/activate
      ./scripts/serve_llm.sh
   ```

   Or point vLLM at a specific local checkpoint directory:
   ```bash
      MODEL_PATH=./local_qwen3_model SERVED_MODEL_NAME=qwen3-local ./scripts/serve_llm.sh
   ```

   To serve the downloaded Qwen 3 4B Instruct 2507 checkpoint:
   ```bash
      MODEL=qwen3-4b-2507 ./scripts/serve_llm.sh
   ```
   This uses `./local_qwen3_model` and keeps the served model name as `qwen3-local`, which matches `configs/experiment.yaml`.

5. On a seprate terminal tab, run
   ```bash
      nohup python src/main.py --config configs/experiment.yaml > "./logs/main_$(date +%Y%m%d_%H%M%S).log" 2>&1 &
   ```
   And all hyperparameters can be changed in configs/experiment.yaml including the dataset name
   The log info can be found in ./logs/ dir

## Project Structure

- `datasets/`: This folder contains the datasets used in the experiments.
  
- `results/`: Stores the self-optimized code generated by the model during each task, as well as the output generated by the model during tests.

- `logs/`: Stores the log file

- `src/`: This folder contains the code implementation.
  
  - `main.py`: The entry point for running the agent.
  - `agent_module.py`: Core implementation of the Gödel Agent, including the self-awareness, self-modification, and action execution logic.
  - `task_*.py`: Evaluation scripts for each task/environment. (adapted from [ADAS](https://github.com/ShengranHu/ADAS))
  - `logic.py`: Stores the generated agent code.
  - `wrap.py`: Used for debugging.
  - `goal_prompt.md`: Contains the goal prompt for the agent.
